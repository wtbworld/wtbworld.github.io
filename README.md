# wtb.exe

A playful personal website for **wtbworld.github.io**.

### Upload

Upload these three files to the root of your GitHub repository:

- `index.html`
- `style.css`
- `script.js`

Then go to **Settings → Pages** in the repository and select:

**Deploy from a branch → main → / (root) → Save**

The site is intentionally image-free, so it works immediately without extra assets.
